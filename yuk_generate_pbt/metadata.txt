about=QGIS plugin (beta — requires an access code). Workflow: enter your beta access code, pick a GPKG + layer + QPT template + (optional) ECW imagery, set scale/colors/variant, then Preview (free — check the sheets first, no quota used) or Generate. Auto scale groups whole regions first (spatial split at the widest gaps, then the scale that fits each region — small parcels get zoomed-in sheets so labels fit). Layouts are loaded from .qpt; parcel styling (KET rule renderer + labeling) is applied via PyQGIS and rendered with QgsLayoutExporter. All desktop app features are kept; no debug/log files are written. Follow us on Instagram @yuktech for updates and feedback; sample QPT template and sample GPKG links are in the README.
